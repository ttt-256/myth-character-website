# 头像替换说明

现在的 `avatar-*.svg` 是**占位头像**（国风纹样 + 名字单字），随时可以换成你自己的人物立绘。

## 怎么替换

**方式一：直接覆盖文件（最省事）**
把准备好的图片改名为同名文件覆盖即可，但要保持 `.svg` 后缀 —— 所以更推荐方式二。

**方式二：换成 jpg / png（推荐）**
1. 把图片放进本目录，例如 `avatar-nezha.jpg`
2. 打开 `js/characters.js`，把对应人物的 `avatar` 字段改掉：

```js
{
    id: 'nezha',
    name: '哪吒',
    avatar: 'assets/avatar-nezha.jpg',   // ← 改这一行
    ...
}
```

首页底部的 6 个小头像在 `index.html` 里，同步把 `src` 改掉即可（搜索 `roster-strip`）。

## 图片建议规格

| 项目 | 建议 |
| --- | --- |
| 尺寸 | 正方形，512×512 或 1024×1024 |
| 比例 | 1:1（页面里以 `border-radius: 50%` 裁成圆形） |
| 格式 | `.jpg` 人像、`.png` 需透明背景时 |
| 单张体积 | 建议 200KB 以内，加载更快 |

## 想加更多人物？

在 `js/characters.js` 的 `CHARACTERS` 数组里照葫芦画瓢新增一项即可，页面会自动出现在名录里 ——
左侧名录、进度点、上一句/下一句全部自动适配，不用改任何其他代码。
