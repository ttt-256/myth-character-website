# 人物头像（故事页顶部 140px 圆形位）

故事页（`nezha.html`、`wukong.html` … ）顶部那个圆形头像，默认读取本目录下的同名 jpg：

| 文件名 | 人物 |
| --- | --- |
| `nezha.jpg` | 哪吒 |
| `wukong.jpg` | 孙悟空 |
| `yangjian.jpg` | 杨戬 |
| `change.jpg` | 嫦娥 |
| `kuafu.jpg` | 夸父 |
| `jingwei.jpg` | 精卫 |

## 用法

把图片按上表命名放进本目录即可，刷新页面就生效 —— 不需要改任何代码。

如果某个文件不存在，页面会自动退回 `assets/avatar-xxx.svg` 占位头像，不会出现裂图。

## 还有一种换法：直接在页面上换

每个故事页头像下方都有「**更换头像**」按钮，选一张本地图片就会立刻替换，
并记在浏览器本地（`localStorage` 的 `avatar_<人物id>` 键）。

注意：这种方式**只存在你这台电脑的这个浏览器里**，换设备或清缓存就没了；
要所有人打开都看到，还是把图片放进本目录。

## 图片建议规格

| 项目 | 建议 |
| --- | --- |
| 尺寸 | 正方形，512×512 或 1024×1024 |
| 比例 | 1:1（页面里按 50% 圆角裁成圆形，建议人脸居中） |
| 格式 | `.jpg`，需要透明背景时用 `.png` 并改页面里的文件名 |
| 体积 | 200KB 以内更利于加载 |

## 2026-10 更新：人物页（story.html）也用这套规则

- 人物页大头像同样按 `nezha.jpg / wukong.jpg / …` 自动读取本目录图片
- 也可以直接**点页面里的头像**（或右上角「换头像」）选本机图片，会记在浏览器本地，
  与故事页的「更换头像」共用同一份存档（`localStorage` 的 `avatar_<人物id>`）
- **右键头像** = 恢复默认占位头像
- 头像右侧的名字、称号、标签、介绍和台词都可以直接点上去改，改动存本机；
  右上角「恢复默认文本」一键还原，「导出本页图片」可存 PNG
